How it works

Retrieval ranks the relevant FDA label passages; the model may only write from them; then every statement is verified against its source before the answer is shown.

  1. 01

    Screen

    Image or signal inputs, identifiable-patient questions, and time-critical emergencies are declined before any retrieval.

  2. 02

    Retrieve

    BM25 retrieval ranks passages from FDA drug labels. Any drug not pre-indexed is fetched live from openFDA on demand.

  3. 03

    Generate

    An answer written by an open-weight model, grounded only in the retrieved passages — or verbatim label quotes with no model at all.

  4. 04

    Verify

    Each statement is checked against its cited source. Anything unverifiable or directive is removed and logged in an audit trail.

Enforced in code, on every statement

Prompting a model to follow FDA's non-device clinical decision support criteria isn't reliable on its own. These checks run in code, on every answer, whichever generator produced it.

Every statement cites its source

Label section, DailyMed link, and label effective date on each statement.

Numbers must appear in the source

A dose, frequency, or threshold that isn't in the cited label is removed.

Directive language is removed

“Give 500 mg” fails. “The label states the starting dose is 500 mg [S1]” passes.

Sources are ranked by trust

Approved healthcare sources are marked; anything else is flagged in the answer, never hidden.

Abstains when unsure

When nothing can be verified against a source, TraceCDS says so instead of guessing.

Label tables are preserved

Dosing tables are converted to Markdown and quoted row by row with their column headers.

Open, and honest about its boundaries

Retrieval, source trust-checking, and the FDA non-device guardrails are open-source code (Apache-2.0). Answers are written by NVIDIA Nemotron, an open-weight model served through the hosted DeepInfra API — your question is sent there to generate the answer, and every statement it returns is still verified against the cited source first. You can self-host instead: point TraceCDS at your own OpenAI-compatible server (Ollama, vLLM) to keep generation in-house, or use the quote-only mode, which runs no model at all.

When FDA labels don't cover a question, TraceCDS can answer from a trust-checked web search — those answers are clearly flagged as falling outside the FDA-label guarantee.
