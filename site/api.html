Developer API · v1

Source-verified drug answers, over HTTP.

Send a drug-information question, get back cited statements — each one quoted from an FDA drug label, linked to DailyMed, and verified against its source before it's returned. The same FDA non-device CDS checks the app runs are reported in every response.

Base URL & authentication

All endpoints live under https://api.tracecds.com. Authenticate every request with the key you were issued, as a bearer token:

# header on every request
Authorization: Bearer YOUR_API_KEY

# or, equivalently
X-API-Key: YOUR_API_KEY

Requests and responses are JSON. /v1/health is the only endpoint that needs no key.

Ask a question

POST/v1/ask

Answer a single drug-information question. Returns the verified statements, their cited sources (with trust tier and label effective date), the four FDA non-device CDS criteria results, any limitations, and any statements that were removed because they couldn't be verified.

# request
curl -s https://api.tracecds.com/v1/ask \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"question": "What are the contraindications for metformin?"}'
# response (abridged)
{
  "status": "answered",
  "question": "What are the contraindications for metformin?",
  "query_used": "What are the contraindications for metformin?",
  "answer_mode": "Written answer",
  "source_mode": "FDA labels, then web",
  "statements": [
    "According to the metformin label (Contraindications): severe renal
     impairment (eGFR below 30 mL/min/1.73 m2); hypersensitivity to
     metformin; acute or chronic metabolic acidosis. [S1]"
  ],
  "citations": [
    {
      "label": "S1",
      "drug": "metformin",
      "section": "Contraindications",
      "source_title": "FDA label: metformin",
      "source_url": "https://dailymed.nlm.nih.gov/...",
      "effective_date": "2026-09-09",
      "trust": "approved",
      "publisher": "FDA / DailyMed"
    }
  ],
  "criteria": [
    {"criterion": 1, "passed": true, "detail": "Text-only input."},
    {"criterion": 2, "passed": true, "detail": "All sources are FDA drug labels."},
    {"criterion": 3, "passed": true, "detail": "Reports what sources say; directive statements removed."},
    {"criterion": 4, "passed": true, "detail": "Each statement cites a source with a link."}
  ],
  "limitations": ["Label information may not reflect newer evidence or guidelines."],
  "warnings": [],
  "removed_statements": []
}

Request body

FieldTypeDescription
questionstringRequired. The drug-information question (≤ 500 characters).
answer_modestringOptional. "Written answer" (default, when the model is available) or "Quoted from label" for exact label quotes only.
source_modestringOptional. "FDA labels, then web" (default), "FDA labels only", or "Web only". Web-sourced answers are flagged as outside the FDA-label guarantee.
historystring[]Optional. Prior questions (oldest first) so follow-ups resolve references.

status is one of answered, abstained (nothing could be verified against a source), or blocked (e.g. an image/signal input, or a time-critical emergency question, which TraceCDS declines by design).

Check drug–drug interactions

POST/v1/interactions

Report what two or more drugs' FDA labels say about interactions among them — passages in one drug's label that name another are surfaced first. Each statement is cited and verified. It reports what the labels say; it does not decide whether to co-prescribe.

curl -s https://api.tracecds.com/v1/interactions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"drugs": ["warfarin", "amoxicillin"]}'

The response has the same shape as /v1/ask.

Service endpoints

GET/v1/health

Liveness check. No key required. Returns {"status":"ok","version":"…"}.

GET/v1/info

Service capabilities: available answer modes, source modes, whether web search and the written-answer model are enabled, and the list of indexed drugs. Key required.
